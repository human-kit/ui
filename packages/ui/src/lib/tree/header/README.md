# Tree.Header

## API reference

### Tree.Header

Name: `Tree.Header`
Description: Non-interactive section label used to name a `Tree.Section`.

| Prop           | Type                             | Default     | Description                                                |
| -------------- | -------------------------------- | ----------- | ---------------------------------------------------------- |
| `children`     | `Snippet`                        | `undefined` | Header label content.                                      |
| `class`        | `string`                         | `''`        | CSS class names for the header element.                    |
| `...restProps` | `HTMLAttributes<HTMLDivElement>` | `-`         | Additional DOM attributes forwarded to the header wrapper. |
