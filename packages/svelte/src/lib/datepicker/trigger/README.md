# DatePicker.Trigger

Button part that opens/closes the calendar popover.

## Responsibility

- Toggles `DatePicker` popover state.
- Integrates with shared interaction-modality focus behavior.
- Exposes focus attributes aligned with root state.

## Usage

```svelte
<DatePicker.Trigger>Open date picker</DatePicker.Trigger>
```
