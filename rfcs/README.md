# RFCs

These are the design documents of the charts. They were written when the charts were their own package, `@human-kit/charts`. The code is now in `packages/ui/src/lib/chart`, and the public imports are `@human-kit/ui` and `@human-kit/ui/chart/scales/*`.

The documents keep the names of that time. Read `packages/charts` as `packages/ui/src/lib/chart`, `@human-kit/charts` as `@human-kit/ui/chart`, and `pnpm size` as `pnpm size:chart`.
